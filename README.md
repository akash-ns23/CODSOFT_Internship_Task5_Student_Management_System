A Java-based Student Management System developed as part of the CodSoft Java Programming Internship. The application allows users to add, search, update, remove and display student records through a simple console-based interface with input validation.

# CODSOFT Java Student Management System

## Project Overview

This project is a console-based Student Management System developed in Java. It enables users to manage student records efficiently through a menu-driven interface.

## Features

* Add Student
* Search Student by Roll Number
* Update Student Information
* Remove Student
* Display All Students
* Input Validation
* Menu-Driven Console Interface

## Technologies Used

* Java
* Scanner Class
* ArrayList
* Object-Oriented Programming (OOP)

## How to Run

1. Compile the program:

```
javac StudentManagementSystem.java
```

2. Run the program:

```
java StudentManagementSystem
```
